# Production Deployment Guide (Shared Hosting)

This document provides a comprehensive guide for deploying SimpleAkunting v4 to **Arenhost** (or similar cPanel-based shared hosting) using the manual database strategy.

## 1. Environment Requirements

- **PHP**: 8.2 or 8.3
- **Database**: MariaDB / MySQL (Unlimited databases plan recommended)
- **Akses**: SSH/Terminal Access (Crucial)
- **Domain**: `v4.simpleakunting.biz.id` (Central)
- **Subdomain**: `*.v4.simpleakunting.biz.id` (Wildcard Tenants)

## 2. Server Configuration

### Folder Structure
Recommended path: `/home/simpleak/simpleakunting-v4`

### Document Root
Point the domain `v4.simpleakunting.biz.id` to:
`/home/simpleak/simpleakunting-v4/public`

### Database Prefix
Most cPanel hosts use a prefix. In this environment: `simpleak_`.
The app is configured to use: `simpleak_dbv4_tenant-`

## 3. Deployment Steps (Standard)

1. **Upload**: Upload the code (excluding `vendor` and `node_modules`).
2. **Install Dependencies** (via SSH):
   ```bash
   composer install --no-dev --optimize-autoloader
   npm install && npm run build
   ```
3. **Setup .env**:
   Create a `.env` file with these production keys:
   ```env
   APP_URL=https://v4.simpleakunting.biz.id
   CENTRAL_DOMAIN=v4.simpleakunting.biz.id
   SESSION_DOMAIN=.v4.simpleakunting.biz.id
   TENANT_DATABASE_PREFIX=simpleak_dbv4_tenant-
   DB_DATABASE=simpleak_central_db
   DB_USERNAME=simpleak_user
   DB_PASSWORD=your_password
   ```

## 4. Initializing Tenants (Manual DB Mode)

Since the database is created manually in cPanel, follow these steps to link them:

### Step A: Initialize Central DB
```bash
php artisan migrate --seed
```

### Step B: Register Tenant
Use the custom tool to link the manual database:
```bash
# Example for 'bisnis1'
php artisan tenant:register bisnis1 bisnis1.v4.simpleakunting.biz.id
```

### Step C: Run Tenant Migrations
```bash
php artisan tenants:migrate --tenant=bisnis1
```

## 5. Maintenance & Updates

Use the `deploy.sh` script to pull updates:
```bash
./deploy.sh production
```
